# 🎨 Arts & Traditions - Plateforme de Gestion d'Événements

> **Projet d'Évaluation** - Site web dynamique en PHP permettant la mise en relation entre artistes et organisateurs d'événements.

---

## 📌 Présentation du Projet

Ce projet a été développé dans le cadre d'un cursus scolaire en supérieur. L'objectif est d'offrir une plateforme fluide où :
* **Les Artistes** peuvent accéder à un espace privé (Dashboard) et gérer leur profil ainsi que leurs prestations.
* **Les Organisateurs** peuvent rechercher des artistes et planifier des prestations.
* **Le Public** peut naviguer sur le site, découvrir les artistes "Arts & Traditions", leurs prestations ainsi que le programme de la journée.

---

## 🛠️ Technologies Utilisées

* **Backend :** PHP (Architecture MVC / Structuration en Modèles et Vues)
* **Base de données :** MySQL (Gérée via phpMyAdmin)
* **Frontend :** HTML5, CSS3 (Design responsive)
* **Environnement de test :** XAMPP / Apache

---

## 🚀 Fonctionnalités Clés

- [x] **Architecture Modulaire :** Header et composants génériques réutilisables (avec gestion dynamique de l'URL de base).
- [x] **Espace Privé :** Dashboards distincts et sécurisés pour les artistes et les organisateurs.
- [x] **Navigation Dynamique :** Détection automatique de la page active dans le menu pour une meilleure UX.
- [x] **Gestion des Prestations :** Affichage dynamique des prestations artistiques à partir de la base de données.
